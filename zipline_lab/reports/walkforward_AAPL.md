# Walk-forward 报告 — AAPL SMA 金叉

- 标的:AAPL(价格取自 bundle `stockdb`,close ≡ adj_close,不连 MySQL)
- 样本内 IS:2013-01-02 .. 2019-12-31
- 样本外 OOS:2020-01-02 .. 2025-12-19
- 网格:short ∈ {5,10,…,50} × long ∈ {20,30,…,200},约束 short<long → 共 174 组
- 执行口径:预筛=T+1 收盘成交·连续满仓·小数股(signal.shift(2));zipline=T+1·整数股·零滑点零佣金

## 方法说明:为何向量化预筛可信

预筛不逐组跑 zipline,而用 pandas 向量化算等效收益给参数排序。底气来自对齐验证(`reports/align_summary.md`)的结论:zipline 与旧引擎在 6/6 组上**信号级 100% 一致**——同样的收盘价喂同样的六行信号公式,产出同样的每日 0/1 信号,已被独立 oracle 钉死。

信号既已证可信,预筛与 zipline 的收益差只来自**执行口径**(T+1 成交价 / 整数股现金拖累 / 再平衡),量级是 bp(见对齐报告 c 块归因)。预筛刻意对齐 zipline 的 T+1:持仓 = signal.shift(2)(signal 日 t → t+1 收盘建仓 → 吃 close[t+1]→close[t+2] 起的收益),只省掉整数股/再平衡。只要 bp 级扰动不翻转排名,预筛 top-k 即真 top-k;top-5 已用 zipline 复核并量化 bp 差(见下),>200bp 触发警告。

## OOS 样本外:IS 最优参 vs buy&hold

IS 最优参(zipline 复核后第一名)= **SMA(25,190)**;仅用它单跑 OOS,不用任何 OOS 数据选参。buy&hold = OOS 首日收盘买入持有到期末。

| 口径 | 区间 | 总收益 | Sharpe(年化) | 最大回撤 |
|---|---|---|---|---|
| SMA(25,190) IS(复核) | 2013-01-02..2019-12-31 | 333.30% | 1.208 | -33.29% |
| SMA(25,190) OOS | 2020-01-02..2025-12-19 | 82.83% | 0.600 | -30.57% |
| buy&hold OOS | 2020-01-02..2025-12-19 | 277.64% | 0.859 | -33.36% |

- **过拟合落差(Sharpe,长度无关的主指标)= -0.608**:IS Sharpe 1.208 → OOS Sharpe 0.600;风险调整后收益近乎腰斩,样本内寻优的优势未在样本外延续。
- 总收益对照(注:IS/OOS 窗口长度不同,总收益不可直接相减,仅作规模直观):IS 复核 333.30% → OOS 82.83%(名义差 -25047 bp)。
- **相对 buy&hold(OOS)= -19481 bp**:策略 82.83% vs 持有 277.64%;择时未跑赢简单持有 → 在此标的/区间,SMA 金叉的样本内优势未转化为样本外超额。

## 结论

1. 预筛可信度:top-5 复核最大 |bp 差| = 76.1 bp(≤200bp),信号级已 100% 对齐,排名可采信。
2. IS 最优 SMA(25,190):Sharpe IS 1.208 → OOS 0.600(落差 -0.608);OOS 总收益 82.83% vs buy&hold 277.64%(-19481bp)。
3. 单标的单窗口结论仅作方法骨架演示;稳健化需 rolling/anchored 多窗前推 + 多标的 + 参数高原(非孤立尖峰)与交易成本敏感性。
