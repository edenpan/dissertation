# 全池 PSO 过拟合对照 —— 现役恒指成分股(sma8）

旧论文(2018)命题的全池现代重做:对**全部现役恒指成分股**逐票用 PSO 调 8 参 SMA 规则(fitness=总收益)对比 buy&hold,量化「PSO 能否找到跑赢市场的参数」。

## 实验设定

- 股票池:现役恒指成分股(index_id=2, expiry_date IS NULL,且库内有日线),共 **81** 只;bundle `stockdb-hk`/XHKG,close≡adj_close,不连 MySQL 取价。
- 样本内 IS:2013-01-02..2019-12-31;样本外 OOS:2020-01-02..2025-12-19(OOS 绝不参与选参)。
- 规则:sma8 状态机(8 窗口 t1..t8∈[2,200] 整数);signal{0,1}→position.shift(2)×当日收益(T+1 收盘成交等效,同 walkforward)。
- PSO:30 粒子×200 iters(名义预算 6000 次/seed),3 seed 取 champion(最优 seed);随机搜索同名义预算 6000 次/seed;朴素 = SMA(20,50) 退化;buy&hold OOS 首日买入持有。
- IS 数据不足跳过:有效 IS session(bundle 内上市日起)< 756(约 3 年)的票**跳过 PSO,只跑 buy&hold 参照**(见跳过清单)。
- zipline 复核:全池 62×2 次 zipline 太贵,只**随机抽 8 只(seed=42)**复核 PSO champion 的 IS 段,bp 差>200 警告。
- 运行:62 只跑 PSO、19 只跳过、0 只失败;总耗时 3746s。

### ★幸存者偏差告警(结论前必读)

股票池用的是**今日**恒指成分股名单回看历史(2013 起),**旧论文当年(2018)的成分股名单已不可考**。今日在册的都是活到现在、多数长期上涨的赢家——用它们回测天然抬高「买入持有」基准,也抬高任何多头择时的表现。本报告结论只作**命题骨架**(PSO 样本内调参→样本外衰减这一结构),不代表当年真实可投资集合的收益,更不能外推为「该策略能赚钱」。

## 结论(诚实口径,与旧论文命题 + 7-05 三票小样本对照)

1. **PSO 能否找到跑赢市场的参数(旧论文命题)**:全池 62 只里,PSO champion 的 OOS 总收益跑赢 buy&hold 仅 **32/62**(52%),OOS 超额中位 **1.38%**。过半标的 OOS 跑赢 buy&hold,但须扣除下述幸存者偏差再审视。
2. **PSO vs 同预算随机(现代公平裁决)**:PSO 的 OOS 胜随机 **39/62**。PSO 在过半标的上 OOS 胜随机,但 IS 早停使随机臂评估更多,该读数对 PSO 已偏保守。
3. **过拟合的量**:PSO champion 的 IS→OOS Sharpe 衰减中位 **-0.969**——样本内高 Sharpe 在样本外大幅回落,是过拟合的直接证据(评估预算越大越易撞 IS 尖峰)。
4. **与 7-05 三票小样本对照**:三票(0005/0700/0941)上曾得「PSO OOS 0/3 胜 B&H、港股择时是弱基准错觉」。全池扩到几十只后,跑赢比例较三票有所回升,但主因是全池含更多今日赢家(幸存者偏差),非择时变强。
5. **幸存者偏差(再次强调)**:池子是今日恒指成分,含幸存偏差,B&H 基准被系统性抬高;任何「跑赢/跑不赢 B&H」的读数都要放在这个抬高的基准上理解。稳健化需当年真实成分名单 + rolling/anchored 多窗前推 + 参数高原 + 交易成本(港股印花税 0.1%/手,只会让择时更差)。

## 附:web 发布口径注记(bt 表 run 26~32)

发布到 `/quant` 的 OOS 净值(0027/0175/1099 的 sma8_pso run)是 **zipline 从 OOS 首日冷启动重放**——sma8 路径依赖状态机在 2020-01-02 重置,与本报告表格里「全史信号切片到 OOS 段」的向量化口径**不是同一条路径**:入场时点在 OOS 前段可能漂移。实测 0027/0175 两口径差 ~50bp 内,**1099.HK 差约 1380bp**(zipline 复跑 39.9% vs 向量化 53.7%),即冷启动路径分歧的实例,非计算错误。比较报告数字与 web 曲线时以本注记为准。
